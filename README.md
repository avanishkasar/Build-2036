# BUILD 2036: ADHIKAR

Submission workspace for **BUILD 2036**, the official hackathon of the 11th TiE Global Summit 2026 (Frontier 03: Digital Infrastructure).

**ADHIKAR** is the trust layer for AI agents on India's payment rails. *Agents think. Adhikar decides.*

| Path | What it is |
|---|---|
| `research/BUILD2036_RESEARCH.md` | Hackathon rules, past TiE and Hack2skill winners, judging rubrics, pitch tips, problem-statement selection, sources |
| `deck/ADHIKAR_BUILD2036.pptx` | 17-slide submission deck with speaker notes for a 3-minute pitch |
| `deck/ADHIKAR_BUILD2036.pdf` | PDF export of the deck |
| `deck/build.js` | pptxgenjs generator for the deck |

| `deck/GEMINI_IMAGE_PROMPTS.md` | Image prompts for Gemini to replace the Canva stock visuals |

**Live prototype:** https://adhikar-sigma.vercel.app/?judge (code in `prototype/`)

The final deck lives in Canva: https://www.canva.com/d/O3wvp_MGJXZN3WD
